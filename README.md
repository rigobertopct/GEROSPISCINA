# GEROS PISCINAS S.R.L. — Página web

Sitio web corporativo de **GEROS PISCINAS S.R.L.**, empresa especializada en mantenimiento integral de recintos de agua, franja de playa y gestión ambiental vinculada al turismo sostenible.

## Contenido

- **Inicio:** Slider con tres bloques temáticos:
  - Sistema Integral de Gestión (S.I.G.)
  - Gestión Ambiental (turismo sostenible, proyecto GEF-PNUD)
  - Mantenimiento Integral (recintos de agua y áreas de influencia)
- **Servicios:** Mantenimiento preventivo-predictivo para recintos de agua y zonas de playa, mantenimiento de urgencia y acompañamiento en mantenimiento constructivo.
- **Contacto:** Formulario y datos de contacto.

## Estructura del proyecto

```
Pagina web/
├── index.html      # Página principal (HTML, CSS y JavaScript)
├── images/         # Imágenes del slider (1.jpg, 2.jpg, 3.jpg)
└── README.md       # Este archivo
```

## Tecnologías

- **HTML5** — Estructura y contenido
- **CSS3** — Estilos, diseño responsive, animaciones y slider
- **JavaScript** — Navegación del slider, menú móvil e interacción
- **Font Awesome 6** — Iconos
- **Google Fonts** — Montserrat y Open Sans

## Cómo ver el sitio

1. Clona o descarga el proyecto.
2. Asegúrate de tener la carpeta `images/` con las imágenes del slider (`1.jpg`, `2.jpg`, `3.jpg`).
3. Abre `index.html` en un navegador o sirve la carpeta con un servidor local (por ejemplo, con la extensión “Live Server” de VS Code).

No requiere instalación de dependencias ni proceso de compilación.

## Diseño

- Paleta: azul corporativo (`#003A99`), celeste (`#9ADBE2`, `#6EC6D1`) y blanco.
- Diseño adaptable a escritorio, tablet y móvil.
- Slider de pantalla completa con scroll interno cuando el texto es largo.
